# StudyFlow

Мой небольшой трекер обучения на Go. Я сделал его, чтобы записывать, что именно изучал сегодня, сколько времени потратил и какие задачи уже закрыл.

Это один из моих первых backend-проектов. Я изучаю Go около трёх месяцев и пока специально не добавлял сюда сложную архитектуру: мне важнее разобраться, как работает HTTP-сервер, хранение данных и обычный CRUD.

## Немного обо мне

Мне 15 лет. Сейчас я учусь писать backend на Go и примерно три месяца осваиваю Linux. Этот репозиторий — мой учебный проект, который я постепенно улучшаю по мере того, как узнаю что-то новое.

## Возможности

- добавление учебных задач с категорией;
- отметка задачи как выполненной;
- запись времени и заметки именно для выбранной задачи;
- общий прогресс и streak по дням;
- простое JSON-хранилище без внешней базы данных;
- HTTP API и минимальный веб-интерфейс.

Пока данные хранятся в JSON-файле. Это не идеальный вариант для большого приложения, но для учебного проекта он удобный и понятный.

## Запуск

Нужен Go 1.23 или новее.

```bash
go test ./...
go run ./cmd/studyflow
```

Открой http://localhost:8080.

По умолчанию данные сохраняются в `data/studyflow.json`. Можно указать другой путь:

```bash
STUDYFLOW_DATA=/tmp/studyflow.json go run ./cmd/studyflow
```

## API

```bash
curl http://localhost:8080/health
curl -X POST http://localhost:8080/api/tasks \
  -H 'Content-Type: application/json' \
  -d '{"title":"Изучить HTTP в Go","category":"Go"}'
curl -X POST http://localhost:8080/api/sessions \
  -H 'Content-Type: application/json' \
  -d '{"task_id":1,"minutes":45,"note":"Написал первый handler"}'
curl -X PATCH http://localhost:8080/api/tasks/1
```
